## 🛠️ Como rodar localmente
```bash
# Clone o repositório
$ git clone https://github.com/Luannax/portfolio_luanna.git

# Entre na pasta
$ cd portfolio_luanna

# Abra o index.html no navegador
```

Você pode editar o arquivo `index.html` e personalizar as imagens na pasta `src/`.
